# 잼얘 — 약관 및 정책

iOS 앱 **잼얘**의 서비스 이용약관과 개인정보 처리방침을 게시하는 저장소입니다.
App Store Connect가 개인정보 처리방침을 웹 URL로 요구하기 때문에 GitHub Pages로 공개합니다.

- 이용약관: `terms.html`
- 개인정보 처리방침: `privacy.html`

원문은 앱 저장소의 `src/constants/legal.ts`이며, 이 폴더의 HTML은
`scripts/build-legal-html.mjs`로 생성됩니다. **직접 수정하지 마세요** — 다음 생성 시 덮어써집니다.
